How to Transfer & Deploy Trained Weights?
1 Download the weights file after training completes: runs/.../weights/best.pt.
2 Copy it into the folder: models/ or weights/ in the project directory.
3 Select the model on the top bar: The system automatically discovers the new weight file and switches the vision pipeline!
