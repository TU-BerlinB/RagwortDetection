Generator komendy treningowej

Skonfiguruj parametry, wygeneruj gotową komendę i uruchom ją na komputerze z GPU lub w Google Colab.

python scripts/train_segmentation.py --model yolov8n-seg.pt --data data/ragwort_parts.yaml --epochs 50 --batch 8 --imgsz 640
# Kliknij 'Wygeneruj komendy' powyżej
Co przenieść na drugi komputer?
1. Katalog data/ragwort_parts/: Zdjęcia oraz etykiety z poligonami (format YOLO segmentacji: klasa x1 y1 x2 y2...).
2. Konfiguracja data/ragwort_parts.yaml: Plik z nazwami klas (flower, leaf, stem).
3. Skrypt treningowy: scripts/train_segmentation.py oraz folder src/.
4. Zależności: pip install -r requirements/requirementsYOLO.txt.
Jak wgrać wagi po treningu do tej aplikacji?

Po zakończeniu treningu skrypt zapisze najlepszy model w:

models/ragwort_segmentation_best.pt

Skopiuj ten plik do folderu models/ na tym komputerze i wybierz go z listy rozwijanej u góry!
